# Manual de marca

Coloque aqui os arquivos reais do manual de marca: paleta de cores (com os valores hex exatos),
tipografia (nomes das fontes e onde baixá-las/licenciá-las), regras de uso do logo, espaçamento e
qualquer outra regra visual fixa.

Diego Design e Vitor Vetor tratam o conteúdo desta pasta como **fonte de verdade inegociável** —
eles nunca inventam cor ou fonte que não esteja documentada aqui. Uma pasta vazia (só com este
README) faz `/rodar-squad-social` parar no Passo 0 antes de gerar qualquer arte.

Formatos aceitos: PDF, imagens (PNG/SVG) ou um `.md` com os valores escritos diretamente.
