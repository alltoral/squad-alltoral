# Identidade visual

Coloque aqui os arquivos de identidade que precisam aparecer nas peças: logo (em variações — claro/
escuro, com/sem texto), mascote ou ícones recorrentes, texturas ou elementos gráficos de assinatura
da marca.

Diego Design usa esses arquivos para posicionar identidade nas extremidades de cada
peça, quando o manual de marca define isso como regra fixa. Uma pasta vazia (só com este README)
faz `/rodar-squad-social` parar no Passo 0 antes de gerar qualquer arte.

Formatos aceitos: PNG (com fundo transparente, de preferência) ou SVG.
